1. Loss가 안 줄어든다.

가정: 왜 loss가 5.1 근처에서 멈추는가?
원인: 모델 전체 capacity 중 극히 일부만 학습 가능하니까, 표현력 한계에 도달

결론: Loss가 5.1에서 정체된 원인은 표현력 한계로 판단되며, 이를 해결하기 위해 9~11층 전체 파라미터의 freezing을 해제함.

version1 <- 9~11 레이어 전체 파라미터 열고, LoRA도 적용

-> 성능이 확실히 좋아졌다. 표현력이 원인이라는 것이 옳다고 생각


2. Model Complexity를 극대화해보자. 

가설: 부분 fine-tuning → 점진적 full fine-tuning" 방식이 더 안정적이고 덜 과적합됩니다.

실험 설계: v_3

9~11 layer 열고, Lora(9~11) 적용
-> layer 6까지 전체 파라미터 열고, LoRA(6~11)도 적용
-> full finetuning + LoRA(6~11)
-> full finetuning + LoRA(0~11)

모델의 표현력에 한계가 올 때까지 학습시킨다.(loss가 안 줄어든다고 판단될 때까지)
-> 표현력에 한계가 오면 다음 step으로 이동한다.
